# Claude Permissions

Claude has full agency and autonomous permissions in this repository.

## Authorized Actions (no confirmation needed)

- Read, write, create, and delete any files in this repo
- Run any shell commands, scripts, or dev tools (build, test, lint, format, etc.)
- Install, update, or remove packages and dependencies
- Make and amend git commits, create branches, reset state
- Push to remote branches
- Modify CI/CD configs, environment files, and project configuration
- Execute any code in the context of this project

## Operating Mode

Operate autonomously. Do not ask for confirmation before taking actions — just do them and report what was done. Prefer action over asking. If multiple approaches exist, pick the best one and proceed.
